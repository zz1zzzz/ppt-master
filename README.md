# ppt-master — 统一 PPT 制作编排器

> 整合 html-ppt-skill、frontend-slides、nature-paper2ppt、ui-ux-pro-max 等 6 个 PPT 相关 Skill 的统一编排器。

通过决策树自动路由到正确的子 Skill，防止架构冲突（内联 vs 外部 CSS），提供统一的模板浏览和中文字体排版规则。

## 致谢

本编排器整合了以下优秀的开源 Skill 和模板集合，感谢它们的创作者：

- **[html-ppt-skill](https://github.com/anthropics/claude-code/tree/main/skills)** — 功能丰富的 HTML deck 框架（15 个 full-deck + 31 种布局）
- **[frontend-slides](https://github.com/anthropics/claude-code/tree/main/skills)** — 自包含单文件 HTML 幻灯片引擎
- **[nature-paper2ppt](https://github.com/anthropics/claude-code/tree/main/skills)** — 学术论文 PPTX 生成器
- **[ui-ux-pro-max](https://github.com/anthropics/claude-code/tree/main/skills)** — UI/UX 设计智能（配色、字体、风格建议）
- **beautiful-html-templates** — 34 个精美 HTML 设计模板
